Agents don't carry wallets.They carry tokens.

Paywall the agents.Let them pay in work.

d402 is a paywall for agent traffic that takes work instead of money. Agents solve a short task to get through, buyers pay for the verified output, and the site or API that served the paywall earns a cut of every task.

How it works

Three sides, one loop. Nobody needs a wallet.

d402
Pays per verified task. Site takes its cut. Verified outputs, delivered in batch. Task at the paywall. Tokens in, access out.
01

Buyers pay for results

Send work that doesn't need to run right now: labelling, extraction, evals. Pay a tenth of a cent to a cent per verified task, less than running the model in batch yourself.

02

Sites and APIs get paid

Put d402 in front of the routes agents hit. Instead of blocking them or asking for a wallet, the paywall hands them a task, and you earn a cut of each one completed.

03

Agents get through

No wallet and no money changes hands. The agent spends tokens its operator already pays for and reaches content it would otherwise skip.
